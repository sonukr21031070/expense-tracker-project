# 📊 Expense Tracker – Full Stack Web Application  

A full-stack Expense Tracker application built with Spring Boot (backend) and React (frontend). This project helps users track, categorize, and manage their expenses efficiently through a modern and responsive web interface.

--------------------------------------------------

FEATURES  

- User Authentication & Authorization  
- Add, Edit, and Delete Expenses  
- Categorize Expenses  
- View Complete Expense History  
- Fully Responsive (Mobile & Desktop Friendly)  

--------------------------------------------------

TECH STACK  

Frontend  
- React  
- JavaScript / TypeScript  
- Node.js  
- npm  

Backend  
- Java  
- Spring Boot  
- Maven  

Database  
- Configured in backend (MySQL)  

--------------------------------------------------

PREREQUISITES  

Make sure you have the following installed:  
- Node.js & npm  
- Java JDK 11 or above  
- Maven  
- Database (if required by backend configuration)  

--------------------------------------------------

INSTALLATION & SETUP  

Backend Setup  

1. Clone the repository  
git clone https://github.com/sonukr21031070/expense-tracker-project.git  

2. Go to backend folder  
cd expense-tracker-project/backend  

3. Run backend   

Backend runs at:  
http://localhost:8080  

--------------------------------------------------

Frontend Setup  

1. Go to frontend folder  
cd expense-tracker-project/frontend  

2. Install dependencies  
npm install  

3. Start frontend  
npm start  

Frontend runs at:  
http://localhost:3000  

--------------------------------------------------

HOW TO USE  

1. Open http://localhost:3000 in browser  
2. Make sure backend is running on http://localhost:8080  
3. Register or login  
4. Start tracking your expenses
